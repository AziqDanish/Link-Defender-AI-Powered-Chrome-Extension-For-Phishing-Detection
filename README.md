🛡️ Link Defender: AI Powered Chrome Extension For Phishing Detection

Link Defender is a Chrome extension that checks links before you click into danger. It scans URLs against live threat-intelligence sources, scores the risk, and warns you — or your team — the moment something looks like phishing.

Features:

Real-time link scanning — every link you click (and every page you land on) is checked against PhishTank and VirusTotal.

0–100 Risk Score — a clear, weighted score (safe / suspicious / dangerous) instead of a vague yes-or-no.

AI-powered "Why?" explanations — powered by Gemini, get a plain-language breakdown of what's actually suspicious about a flagged domain, plus one actionable tip.

Offline heuristic fallback — even without API access, Link Defender flags typosquatting, IP-based URLs, sketchy TLDs, and missing HTTPS.

Telegram alerts — automatically notify a group chat the moment a confirmed phishing link is detected.

Right-click scanning — check any link on a page without clicking it, straight from the context menu.

Scan history dashboard — a searchable, filterable log of every scan, exportable to CSV.

On-page warning overlay — a blocking modal for dangerous links, with a lightweight "all clear" animation for safe ones.

Smart caching — verified URLs are cached for 24 hours so you're not re-scanning the same link over and over.
